

## 1. Базовый случай и шаг рекурсии

* **Базовый случай (условие выхода из рекурсии):**
  `if (n <= 1) return 1;`
  Определяет условие, при котором рекурсивные вызовы прекращаются и функция возвращает точное значение (`1`) без новых рекурсивных вызовов (для $n \le 1$).

* **Шаг рекурсии (рекурсивный переход):**
  `return n * F(n - 1);`
  Функция сводит задачу вычисления $F(n)$ к более простой подзадаче $F(n-1)$, умножая результат её выполнения на $n$.

---



При вызове `F(4)` сначала происходит погружение в рекурсию (вызовы вниз по стеку), а затем возврат значений наверх при выходе из каждого вызова.

| Вызов | Глубина стека | Возвращаемое значение | Пояснение / Расчёт |
| :--- | :---: | :--- | :--- |
| **`F(4)`** | 1 | **`24`** | Ждёт `4 * F(3)` → $4 \times 6 = 24$ |
| **`F(3)`** | 2 | **`6`** | Ждёт `3 * F(2)` → $3 \times 2 = 6$ |
| **`F(2)`** | 3 | **`2`** | Ждёт `2 * F(1)` → $2 \times 1 = 2$ |
| **`F(1)`** | 4 | **`1`** | Срабатывает базовый случай ($1 \le 1$) |

---

## 3. Анализ ситуации при вызове F(-1) и изменении условия на n == 1

Если изменить базовое условие на `if (n == 1)`, то функция будет выглядеть так:
```java
static int F(int n) { 
    if (n == 1) return 1; 
    return n * F(n - 1); 
}
