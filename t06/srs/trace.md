

## 1. Ручная трассировка циклического сдвига влево на 1 позицию

**Логика:** Сохраняем `temp = a[0]`, смещаем элементы влево `a[i] = a[i + 1]` для $i$ от $0$ до $n - 2$, затем помещаем буфер в конец: `a[n - 1] = temp`.

* **Перед началом:** `temp = a[0] = 4`

| Шаг | i | Состояние массива `a` после шага | Пояснение |
| :---: | :---: | :--- | :--- |
| **0** | — | `{4, 1, 7, 3, 9}` | Исходное состояние, `temp = 4` |
| **1** | 0 | `{1, 1, 7, 3, 9}` | `a[0] = a[1]` (значение `1`) |
| **2** | 1 | `{1, 7, 7, 3, 9}` | `a[1] = a[2]` (значение `7`) |
| **3** | 2 | `{1, 7, 3, 3, 9}` | `a[2] = a[3]` (значение `3`) |
| **4** | 3 | `{1, 7, 3, 9, 9}` | `a[3] = a[4]` (значение `9`) |
| **5** | — | `{1, 7, 3, 9, 4}` | `a[4] = temp` (запись из буфера) |

**Итоговый массив:** `{1, 7, 3, 9, 4}`

## 2. Ручная трассировка разворота массива на месте

**Логика:** Меняем местами элементы `a[i]` и `a[n - 1 - i]` для $i$ от $0$ до $\lfloor n / 2 \rfloor - 1$.  
При $n = 5$ граница цикла: $n / 2 = 5 / 2 = 2$ (выполняются итерации для $i = 0$ и $i = 1$).

| Шаг | i | Меняются элементы (индексы) | Состояние массива `a` после обмена |
| :---: | :---: | :---: | :--- |
| **0** | — | — | `{4, 1, 7, 3, 9}` |
| **1** | 0 | `a[0]` и `a[4]` (значения 4 и 9) | `{9, 1, 7, 3, 4}` |
| **2** | 1 | `a[1]` и `a[3]` (значения 1 и 3) | `{9, 3, 7, 1, 4}` |

* **Количество выполненных обменов:** **2 обмена**.
* **Почему цикл идет только до `n / 2`:** Каждый обмен меняет местами сразу парами два элемента — с начала и с конца массива. Если продолжить цикл дальше половины, то элементы, которые уже поменялись местами, будут поменяны обратно, и массив вернётся в исходное неотсортированное состояние. Элемент посередине (при нечётном $n$) остаётся на своем месте.

## 3. Ошибка алгоритма поиска минимума с `min = 0`

### Пример массива, на котором алгоритм ошибается:
Массив из положительных чисел: `a = {4, 1, 7, 3, 9}` (или любая последовательность, где все элементы больше 0, например `{5, 10, 15}`).

### Почему возникнет ошибка:
Если алгоритм ищет **значение** минимума и начинается с `min = 0`, то при проверке любого элемента $a[i] > 0$ условие $a[i] < min$ никогда не выполнится. В результате алгоритм вернёт `0`, хотя такого элемента даже нет в массиве.

### Как исправить начальное значение:
1. **Если `min` хранит значение:** Инициализировать первым элементом массива:  
   `int min = a[0];` (затем цикл запускать с $i = 1$).
2. **Если `min` хранит индекс минимального элемента:** Инициализировать нулевым индексом:  
   `int min_index = 0;`
