## 2. Таблица ручной трассировки (a = 48, b = 18)

| Итерация | Условие (b ≠ 0) | r := a mod b | a := b | b := r | Состояние переменных после итерации |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Старт** | — | — | — | — | a = 48, b = 18, r = не задействован |
| **1** | Да (18 ≠ 0) | 48 mod 18 = 12 | a = 18 | b = 12 | a = 18, b = 12, r = 12 |
| **2** | Да (12 ≠ 0) | 18 mod 12 = 6 | a = 12 | b = 6 | a = 12, b = 6, r = 6 |
| **3** | Да (6 ≠ 0) | 12 mod 6 = 0 | a = 6 | b = 0 | a = 6, b = 0, r = 0 |
| **Выход** | Нет (0 ≠ 0) | — | — | — | Цикл завершается |

* **Результат (вывод):** `6`
