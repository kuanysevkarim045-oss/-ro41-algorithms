# Практическая работа: Перевод секунд в часы, минуты и секунды

## Описание
Консольное приложение на языке C#, которое переводит заданное целое неотрицательное число секунд в часы, минуты и секунды с защитой от некорректного ввода.

## Результаты тестирования

| Входные данные ($N$) | Ожидаемый результат | Фактический результат | Статус |
| :--- | :--- | :--- | :--- |
| **3725** | 1 ч. 2 мин. 5 сек. | 1 ч. 2 мин. 5 сек. | Пройдено |
| **59** | 0 ч. 0 мин. 59 сек. | 0 ч. 0 мин. 59 сек. | Пройдено |
| **86399** | 23 ч. 59 мин. 59 сек. | 23 ч. 59 мин. 59 сек. | Пройдено |
| **0** | 0 ч. 0 мин. 0 сек. | 0 ч. 0 мин. 0 сек. | Пройдено |
| **-15** (некорректный) | Ошибка: количество секунд не может быть отрицательным. | Ошибка: количество секунд не может быть отрицательным. | Пройдено |
| **abc** (некорректный) | Ошибка: введено не целое число. | Ошибка: введено не целое число. | Пройдено |
